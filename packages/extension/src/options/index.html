GRabbit Companion Settings

Configure desktop integration, download interception rules, and media sniffing.

Desktop RPC Connection

GRabbit extension connects locally to your running GRabbit desktop app via high-speed HTTP RPC.

The security token protects your desktop queue from unauthorized local requests.
⚠️ Forwarding cookies over unencrypted LAN HTTP can expose your web sessions. Leave disabled unless using a secure private tunnel.

Download Interception Rules

Automatically catch downloads started in Chrome/Edge/Firefox and transfer them directly to GRabbit multi-connection engine.

Files with these extensions will be grabbed automatically by GRabbit.
Downloads initiated on these websites will NOT be intercepted.

Video & Media Sniffer

Detect streaming videos and audio files on web pages with an interactive floating pill.

Extension Updates & Reload

Check for the latest GRabbit Chrome Extension release on GitHub or reload the unpacked extension immediately.
